🎅 Letters to Santa

Code Dojo · .NET MAUI on a Meta Portal Mini
Team: ______________________
Mrs Claus is modernising Santa's Christmas processes. Children's handwritten letters are hard to read, and Santa doesn't want to give the wrong presents. She wants a tablet app where children choose their presents, add anything else in a letter, and complete a Naughty or Nice questionnaire so Santa knows if they've been good this year.

🎯 User stories

  1. As a child I enter my name and age so Santa knows who the letter is from. (provided in the starter)
  2. As a child I tap pictures of presents to choose up to 5, so I don't need to write neatly.
  3. As a child I write a letter to add anything else I'd like.
  4. As a child I answer a short set of yes/no Naughty or Nice questions.
  5. As a child I see my letter, find out if I'm on the Nice List, and send it to Santa.
  6. As Santa I open Santa's Workshop to read every letter with each child's verdict.
  7. As an elf I see a production list of how many of each present to make (nice children only!).

🧪 Katas: make the tests go green first (SantaLetters.Core)

#ClassRule
1NiceListCalculator Score 0–100 = weighted share of “nice” answers. Some questions are phrased naughtily (“Have you told any fibs?”) so No is nice; use each question's NiceAnswer. Unanswered = not nice. Verdicts: ≥85 Super Nice, ≥60 Nice, ≥35 Almost Nice, else Naughty.
2LetterValidator Name required · age 1–16 · 1–5 presents, no duplicates · letter ≤ 500 characters · every question answered.
3JsonLetterStore Save letters to a JSON file on the device. They survive restarts, come back newest first, and can be deleted.

📺 Connecting a Portal Mini

  1. On the Portal: Settings → Debug → ADB Enabled.
  2. Plug USB-C into the back and tap Allow on the debugging prompt.
  3. Check adb devices -l. If it's missing, toggle ADB off and on again.

🧩 MAUI snippets

View model (CommunityToolkit.Mvvm) 
public partial class LetterViewModel : ObservableObject
{
    [ObservableProperty]
    public partial string Wishes { get; set; } = "";

    [RelayCommand]
    private Task NextAsync() =>
        Shell.Current.GoToAsync(nameof(QuestionnairePage));
}
Register a page and route 
// MauiProgram.cs
builder.Services.AddTransient<LetterViewModel>();
builder.Services.AddTransient<LetterPage>();
// AppShell.xaml.cs
Routing.RegisterRoute(nameof(LetterPage), typeof(LetterPage));
Tappable tiles (works for touch and mouse) 
<CollectionView ItemsSource="{Binding Presents}"
    SelectionMode="Single"
    SelectedItem="{Binding TappedPresent, Mode=TwoWay}">
  <CollectionView.ItemsLayout>
    <GridItemsLayout Orientation="Vertical" Span="6" />
  </CollectionView.ItemsLayout>

Handle the tap in OnTappedPresentChanged, then set TappedPresent = null so the same tile can be tapped again.

Handy APIs
  • FileSystem.AppDataDirectory: where to save the JSON file
  • await DisplayAlertAsync(title, msg, "Delete", "Keep")
  • Shell.Current.GoToAsync("..") back · "//welcome" home
  • LetterDraft: singleton holding the letter between pages
